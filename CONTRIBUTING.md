# Участие в проекте

Спасибо, что хотите помочь. Ниже — правила, которые держат проект безопасным для чужих календарей.

## Перед изменением

- Прочитайте [архитектуру](docs/ARCHITECTURE.md): там описаны слои, порты, потоки данных и принятые решения.
- Правила безопасности остаются в силе: удаление только по полностью прочитанному календарю и только
  показанного в предпросмотре, ошибка входа не повторяется, сертификат закрепляется, события пользователя в
  приёмнике не меняются.

## Код

- C#, .NET Framework 4.8 (Windows 7 SP1+), Exchange 2007 SP2…2013. Принципы: DRY, KISS, SOLID, YAGNI,
  разделение ответственности.
- Ядро (`IwoBridge.Core`) работает без ввода-вывода и сети. Типы EWS живут только в `IwoBridge.Ews`, COM
  Outlook — только в `IwoBridge.Outlook`, WPF — только в `IwoBridge.Wpf`. Это проверяют архитектурные тесты.
- Комментарии пишутся по-русски и объясняют, зачем код устроен именно так. Тексты для пользователя собраны в
  `Messages/ErrorMessages.cs`.
- Скрипты `build\*.ps1` — только ASCII: Windows PowerShell 5.1 читает UTF-8 без BOM как ANSI.

## Данные

- В коде, тестах, документах и снимках экрана используются только синтетические данные и домены
  `example.test` и `example.com`.
- Снимки экрана снимаются в демонстрационном режиме (`--demo`).

## Проверка

```powershell
dotnet build IwoBridge.sln
dotnet test  IwoBridge.sln
```

Новое поведение сопровождается тестами. После изменения `PackageReference` выполните
`dotnet restore IwoBridge.sln` и закоммитьте lock-файлы.
