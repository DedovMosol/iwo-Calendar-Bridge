**Скачать.** `iwo-Calendar-Bridge-x64.zip` — для 64-битных Windows 7 SP1, 8.1, 10 и 11. `iwo-Calendar-Bridge-x86.zip` —
для 32-битных Windows (работает и на 64-битных). Нужен .NET Framework 4.8. Распакуйте архив в папку с правом записи
(не `Program Files`) и запустите `IwoCalendarBridge.exe`. Установка и права администратора не нужны.

**Проверка архива.** `Get-FileHash .\iwo-Calendar-Bridge-x64.zip -Algorithm SHA256` — значение должно совпасть со
строкой этого архива в `SHA256SUMS.txt`.
