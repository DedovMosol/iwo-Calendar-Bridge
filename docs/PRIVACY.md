# Политика конфиденциальности

Документ описывает, какие данные обрабатывает **iwo Calendar Bridge**, где они хранятся и куда передаются.
Программа работает локально на компьютере пользователя.

## Какие данные обрабатываются

- Содержимое событий календаря: тема, время, место, описание, пометки занятости и конфиденциальности.
- Вложения событий.
- Учётные данные для входа на серверы Exchange (имя пользователя и пароль).
- Параметры подключения: адрес сервера, адрес ящика, часовой пояс, отпечаток сертификата.
- Настройки копирования: источник, выбранный календарь Outlook, период, правило для личных событий, интервал.

## Где данные хранятся

- **Учётные данные** — в диспетчере учётных данных Windows (защита DPAPI, доступ только у текущего
  пользователя), если в окне «Подключение» стоит отметка «Запомнить». Без отметки пароль хранится только в памяти
  до закрытия программы, а имя пользователя записывается в файл подключения. В файлы программы пароль не
  записывается.
- **Параметры подключения и настройки копирования** — в файлах `config\connection.json`,
  `config\source-connection.json`, `config\mailboxes\*.json` (добавленная почта) и `config\copy.json` рядом с
  программой.
- **Манифест удаляемого** — CSV-файл в папке `manifests` рядом с программой, записывается перед каждой
  очисткой. Содержит вид элемента, тему, время начала и конца и идентификатор каждого удаляемого события, без
  описаний и вложений. Файлы хранятся, пока пользователь их не удалит.
- **Журнал непредвиденных ошибок** — `logs\crash.log` рядом с программой: время и технический текст ошибки.
  Пароли в него не попадают, адрес сервера или ящика может встретиться в тексте ошибки. Размер — не больше
  1 МБ и одной старой копии.
- **Вложения при копировании из Outlook** — во временной папке пользователя на время чтения, удаляются сразу
  после чтения.

## Куда данные передаются

- Только между календарями, которые выбрал пользователь: Outlook на этом компьютере и серверы Exchange по EWS.
- Сторонних серверов, облаков, аналитики, телеметрии и автообновления нет. Разработчик данных не получает.
- Соединения с Exchange — только HTTPS. Сертификат сервера закрепляется по отпечатку, перехват HTTPS сторонним
  ПО распознаётся и показывается как ошибка подключения.
- Outlook только читается, программа ничего в нём не меняет.
- Демонстрационный режим (`--demo`) работает с выдуманными данными в памяти и в сеть не обращается.

## Личные события

События с пометкой «Частное» или «Конфиденциальное» по умолчанию переносятся как «Занято»: тема «Личное», без
места, описания и вложений. Правило меняется в строке «Правила» вкладки «Копирование».

## Удаление данных

- Настройки, манифесты и журнал удаляются вместе с папками `config`, `manifests` и `logs`.
- Учётные данные удаляются из диспетчера учётных данных Windows командами
  `cmdkey /delete:IwoCalendarBridge/ews` и `cmdkey /delete:IwoCalendarBridge/ews-source`. Пароль добавленной
  почты удаляет кнопка «Убрать из списка» на вкладке «Очистка».
- Автозапуск выключается снятием отметки «запускать с Windows».

## Ответственность пользователя

Пользователь обеспечивает правомерность доступа к календарям и переноса данных между ними в соответствии с
политиками своей организации и применимым законодательством.
