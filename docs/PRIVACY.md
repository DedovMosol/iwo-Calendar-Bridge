# Политика конфиденциальности

Документ описывает, какие данные обрабатывает приложение **iwo Calendar Bridge**, где они хранятся и
куда передаются. Приложение работает полностью локально, в периметре пользователя, и не содержит
данных какой-либо организации.

## Какие данные обрабатываются

- Содержимое событий календаря: тема, время, место, описание, организатор и участники, пометки
  занятости и приватности.
- Вложения событий.
- Учётные данные для входа на сервер-приёмник (имя пользователя и пароль).
- Параметры подключения: адрес сервера, адрес ящика, часовой пояс, отпечаток сертификата.

## Где данные хранятся

- **Учётные данные** — только в диспетчере учётных данных Windows (защита DPAPI, доступ только у текущего
  пользователя этой машины). Окно «Подключение» записывает их туда само; в файлы конфигурации и журналы
  пароль не записывается.
- **Параметры подключения** — в локальном файле `config/connection.json` на машине пользователя
  (в систему контроля версий не попадает).
- **Кэш сопоставления и журнал операций** — в локальной базе SQLite на машине пользователя. Журнал
  по умолчанию не содержит тем и тел событий.
- **Манифест удаляемого** — CSV-файл в локальной папке манифестов, записывается перед каждой очисткой.
  Содержит вид элемента, тему, время начала и конца и идентификатор каждого удаляемого события — без
  описаний, участников и вложений. Темы нужны, чтобы человек мог проверить удалённое и найти его в
  «Удалённых». Файлы никуда не передаются и не удаляются автоматически: пользователь хранит или удаляет их
  сам. Папка манифестов в систему контроля версий не попадает.
- **Журнал непредвиденных ошибок** — `logs/crash.log` рядом с программой: время и технический текст ошибки
  (тип, стек вызовов). Паролей не содержит; адрес сервера или ящика в тексте ошибки встретиться может. Не
  больше 1 МБ и одной старой копии; никуда не передаётся, удаляется пользователем.
- **Вложения** — во временной папке на время переноса и удаляются после успешной обработки; очищаются
  также при запуске.

## Куда данные передаются

- Только между двумя серверами Microsoft Exchange, которые указал пользователь: чтение из источника и
  запись в приёмник.
- Никаких сторонних серверов, облаков, аналитики и телеметрии. Разработчик не получает никаких данных.
- Сетевые соединения защищены TLS; адреса без шифрования (`http://`) программа не принимает. Сертификат
  сервера проверяется с закреплением по отпечатку, а перехват HTTPS сторонним ПО распознаётся и приводит к
  понятной ошибке, а не к скрытой передаче.
- Демонстрационный режим (`--demo`) работает с выдуманными данными в памяти и в сеть не обращается.

## Приватные события

События, помеченные как личные (Private), по умолчанию переносятся как «Занято» без темы, описания и
вложений. Их содержимое не выгружается во временные файлы и не пишется в журнал.

## Удаление данных

- Локальный кэш, журнал, манифесты и параметры подключения удаляются вместе с соответствующими файлами
  (`config/`, база SQLite, журналы, папка манифестов).
- Учётные данные удаляются из диспетчера учётных данных Windows командой
  `cmdkey /delete:IwoCalendarBridge/ews`.

## Ответственность пользователя

Пользователь обеспечивает правомерность доступа к обоим календарям и переноса данных между доменами в
соответствии с политиками своей организации и применимым законодательством.

## Изменения

Актуальная версия политики публикуется вместе с исходным кодом. Существенные изменения отражаются в
