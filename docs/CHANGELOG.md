# Журнал изменений

## 0.12 — история операций, консоль, пошаговая запись копий

**История и консоль**
- Кнопка «История» (Ctrl+H): копирования вручную и по расписанию и очистки. Когда, откуда и куда, период,
  сколько создано, перезаписано, удалено и не удалось, итог, длительность и подробности, итог за 7 дней.
- Журнал в файле `logs\history.jsonl`: JSON Lines, UTF-8, время в UTC. Больше 1 МБ — перенос в
  `history.1.jsonl`.
- Программа, запущенная из `cmd` или PowerShell, выводит туда начало и итог каждой операции. Вывод
  перенаправляется в файл: `IwoCalendarBridge.exe > run.log`. Остановленная консоль (выделение текста в её окне)
  не задерживает программу.

**Копирование**
- Копия пишется по шагам: событие с отметкой «не дописано», вложения по одному запросу на файл, исключения серии,
  отпечаток последним. Сбой удаляет созданное, недописанная копия перезаписывается при следующем запуске.
- Серия пересоздаётся так: сначала новая копия, затем удаление прежней.
- Исключение серии находится по ближайшему началу в пределах 12 часов. Изменённое повторение, которого нет в
  серии копии, итог перечисляет как замечание, копия при этом записывается.
- Перечень календаря по EWS читается страницами с перекрытием на один элемент. Удаление или вставка во время
  чтения распознаются, перечень читается заново.
- Ошибки удаления копии повторяются и останавливают пакет так же, как ошибки других запросов.
- После обновления серии с изменёнными повторениями один раз перезаписываются: в отпечатке повторения теперь
  учтена пометка «личное», а текстовые поля отделены однозначно.
- Создание события и вложения после отправленного запроса не повторяются. На резервный адрес они переходят,
  только если запрос не ушёл.
- Ошибка соединения, таймаут, квота или `ServerBusy` останавливает пакет, если повторилась на следующем событии
  подряд. Ошибка входа, прав или сертификата останавливает его сразу.
- Личные повторения серии подчиняются правилу для личных событий.
- Годовые серии «раз в N лет» из Outlook.
- Если Outlook занят или закрыт во время чтения описания, чтение прерывается целиком и не даёт копию без
  оформления.

**Очистка**
- События «весь день» попадают в период по местной дате календаря.
- Отказ сервера по отдельному событию не останавливает очистку. Удаляются остальные события и повторения серий
  на границе периода, итог и «История» называют число отказов.
- Кнопка «Изменить…» меняет пароль и адрес добавленного ящика. Ящик без сохранённого пароля остаётся в списке
  с пометкой «нужен пароль».

**Подключение**
- Без закреплённого отпечатка молча принимается только сертификат без ошибок цепочки и имени. Остальные, в том
  числе выписанные на другое имя при подключении по IP, показываются человеку для решения.
- Чтение и запись одного подключения переходят на резервный адрес вместе.

**Outlook**
- Вызов ограничен 10 минутами без признаков работы. Пока жив зависший поток, следующий не заводится.
- Outlook ищется только в сеансе текущего пользователя.

**Программа**
- Повторный запуск показывает окно уже работающей программы.
- После сна и смены системного времени срок автокопирования считается от последнего запуска, просроченный
  запуск выполняется через минуту.
- Запись автозапуска обновляется, только если записанный в ней файл программы больше не существует.
- Пять непредвиденных ошибок за минуту закрывают программу с сообщением и записью в `logs\crash.log`.
- Файл настроек копирования, который не удалось прочитать, не перезаписывается.

## 0.11 — добавленная почта, «Запомнить»

- Вкладка «Очистка»: кнопка «Добавить почту…» подключает ещё один ящик по EWS, «Убрать из списка» убирает его.
  Календарь ящика при этом не меняется.
- Окно «Подключение»: отметка «Запомнить». Без неё пароль хранится в памяти до закрытия программы, при следующем
  запуске программа его спросит.

## 0.10 — копирование, автокопирование, справка

**Копирование «откуда → куда»**
- Источник — любой календарь Outlook этого компьютера (свои, других ящиков профиля, «Общие календари») или
  календарь ящика по EWS. Приёмник — ящик по EWS.
- Синхронизация за период по разнице: создать, перезаписать, пересоздать серию, удалить копию. Предпросмотр с
  выбором строк, подтверждение, итог по каждому событию.
- Копии помечаются extended properties `IwoBridgeSourceId` и `IwoBridgeContentHash`. События пользователя в
  приёмнике остаются без изменений, совпадающее с ними событие по умолчанию не копируется.
- Серии с изменёнными и удалёнными вхождениями, вложения (файлы и вложенные элементы как `.msg`), описание с
  оформлением и картинками (RTF, `PR_RTF_COMPRESSED`).
- Private и Confidential: только «занято», полностью или не копировать.
- Запись в часовом поясе календаря приёмника, совместимом со схемой Exchange 2007.

**Автокопирование**
- «Раз в N» от 5 минут до суток, скользящий период, работа из области уведомлений, автозапуск при входе в
  Windows, настройки в `config\copy.json`.
- Запуски по одному, ожидание открытых диалогов и очистки, пауза при ошибке входа или прав до изменения
  подключения, одно уведомление на одну проблему.

**Outlook**
- Позднее связывание COM без Office Interop, отдельный STA-поток с фильтром сообщений, ограничение времени
  вызова, восстановление подключения после перезапуска Outlook.
- Выбор календаря из списка, по ФИО владельца или части названия. Календарь, открытый в Outlook, выбран по
  умолчанию.

**Окна**
- Вкладки «Копирование» и «Очистка», подключения «Приёмник…» и «Источник (EWS)…».
- Диалоги в стиле программы с кнопками, подписанными действием.
- Встроенная справка (F1).

## 0.9 — очистка календаря

**Очистка**
- Весь основной календарь или период. Предпросмотр «Будет удалено» и «Останется» с причиной.
- Удаление в «Удалённые» или окончательно, пакетами, с остановкой после текущего пакета.
- Подтверждение вводом адреса ящика, CSV-манифест удаляемого до первого удаления.
- Серии на границе периода — удаление только вхождений внутри периода.
- Повторное чтение перед удалением, удаляется только показанное в предпросмотре.

**Подключение EWS**
- Поле «Сервер» принимает имя, IP, `host:port` или полный адрес EWS.
- Резервный адрес сервера, проверка подключения по каждому адресу.
- Закрепление сертификата (SHA-256 или SHA-1) для каждого адреса, распознавание HTTPS-инспекции.
- Пароль в диспетчере учётных данных Windows.
- Классификация ошибок EWS, повторы с паузой для временных ошибок.

**Окна**
- Адаптивная разметка от 720×480 до 4K, таблицы с виртуализацией строк.
- Высокая контрастность Windows, озвучивание сообщений экранным диктором, F5, Esc и Alt-клавиши.
- Журнал непредвиденных ошибок `logs\crash.log`, демонстрационный режим `--demo`.

**Сборка**
- Portable-архивы x86 и x64, CI на GitHub Actions, lock-файлы пакетов, архитектурные тесты зависимостей.
